# La Table d’Or

Site vitrine moderne pour un restaurant avec système de réservation en ligne, développé avec React, TypeScript et Vite.

---

# Présentation du projet

**La Table d’Or** est une application web conçue pour offrir une expérience moderne et immersive autour d’un restaurant.

Le projet permet aux utilisateurs de :

- découvrir l’univers du restaurant
- consulter les menus et spécialités
- réserver une table en ligne
- accéder aux informations de contact et horaires
- naviguer sur une interface fluide et responsive

L’objectif principal était de concevoir une interface élégante, performante et responsive tout en appliquant une architecture frontend propre et maintenable.

# Installation

## 1. Cloner le projet

```bash
git clone https://github.com/leofleury72-bot/La-Table-D-or.git
```

## 2. Installer les dépendances

```bash
npm install
```

---

# Lancer le projet

```bash
npm run dev
```

L’application sera disponible sur :

```bash
http://localhost:5173
```
